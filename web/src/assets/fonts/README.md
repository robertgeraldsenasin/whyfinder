# Self-hosted fonts

Latin subsets (WOFF) of two SIL Open Font License fonts, made with `pyftsubset` from the Google Fonts
releases; the licences sit next to them. The other fonts come from Fontsource (see `src/main.ts`).

| File | Font | Licence |
| --- | --- | --- |
| `anton-latin-400.woff` | Anton Regular | [OFL-Anton.txt](OFL-Anton.txt) |
| `comic-relief-latin-400.woff`, `comic-relief-latin-700.woff` | Comic Relief Regular and Bold | [OFL-ComicRelief.txt](OFL-ComicRelief.txt) |
