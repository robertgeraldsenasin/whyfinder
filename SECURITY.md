# Security

Please report vulnerabilities privately through GitHub's "Report a vulnerability" (Security tab) or by
email to robertgeraldsenasin@gmail.com. Expect a reply within 7 days.

Scope: the API (`src/whyfinder/serve`), the web demo, CI workflows and dependencies. No secrets are
needed for CI; an optional hosted-LLM key lives only in a local, git-ignored `.env`.
