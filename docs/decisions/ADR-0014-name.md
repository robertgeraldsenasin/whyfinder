# ADR-0014: Name: Whyfinder

- **Status:** Accepted
- **Date:** 2026-11-17
- **Deciders:** Robert Gerald Senasin

## Context

The working title "Laro" was Tagalog; the product is for players everywhere. Names with game nouns collided with existing Steam games or game apps (Sightline, Lodestar, Questlog, NextQuest).

## Options considered

1. Pathlight
2. Whyfinder
3. Hintsight
4. Breadcrumbs

## Decision

Whyfinder (wayfinder → whyfinder). Tagline: "Find your next game. Know why." "Steam" stays out of the name (Valve's mark) and appears only in descriptions.

## Consequences

Short, pronounceable, says what it does.
