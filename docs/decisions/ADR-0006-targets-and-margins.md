# ADR-0006: Success targets and gate margins

- **Status:** Proposed (fix after M1 baselines)
- **Date:** 2026-11-17
- **Deciders:** Robert Gerald Senasin

## Context

Targets set before seeing baselines are guesses.

## Options considered

1. Fix now
2. Fix after M1 baselines

## Decision

Start with the proposed values in 01_PRD.md and 07_EVALUATION.md (δ = 0.005 NDCG@10, 1 point for rates). After M1, record the real baselines here and confirm or adjust each target once.

## Consequences

Targets become evidence-based; later changes require a new ADR.
